# Linked List

Ten core linked-list exercises in C++17. Every file is a standalone program and uses standard input.

| # | Problem | Main technique |
|---|---|---|
| 1 | Create and Traverse | node construction |
| 2 | Insert at Beginning | head update |
| 3 | Insert at End | tail traversal |
| 4 | Delete by Value | pointer relinking |
| 5 | Reverse Linked List | three pointers |
| 6 | Middle Node | slow/fast pointers |
| 7 | Detect Cycle | Floyd's algorithm |
| 8 | Merge Sorted Lists | dummy head |
| 9 | Remove Nth From End | two pointers |
| 10 | Doubly Linked List Traversal | prev/next links |

Compile any solution:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic 05_reverse_linked_list.cpp -o solution
```
